# Data Directory

This folder is intended to hold the raw and processed datasets for the Credit Risk Scoring System.

**Note:** The CSV and PKL data files in this folder are ignored by Git (`.gitignore`) to prevent committing large data files to the repository.

### Required Datasets

To proceed with Phase 1 (Data & EDA), please download the following datasets from Zindi and place them in this folder:

1.  **African Credit Scoring Challenge**
    *   Download link: [Link to Zindi Competition] (You will need to search for this on Zindi and accept the rules)
    *   Place the `Train.csv` and `Test.csv` (and any other relevant files) here.

2.  **Loan Default Prediction Challenge (SuperLender)**
    *   Download link: [Link to Zindi Competition] (You will need to search for this on Zindi and accept the rules)
    *   Place the `train.csv` and `test.csv` (and any other relevant files) here.

*(The `synthetic_ng_credit_data.csv` generated by our Python script in `ml/` can also be copied here or referenced directly.)*
